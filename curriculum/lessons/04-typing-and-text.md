# Typing and text

EWURK topic: **Lesson 4 — Typing and text**

Instructor: read each numbered step aloud. Attendance is marked in EWURK after class—not on this page.

## Goal

Everyone can open a text editor, type a short paragraph with spaces and punctuation, and fix mistakes with backspace without panic.

## Materials

- EWURK lab Linux desktop
- Text editor (Text Editor / gedit)
- Optional: printed keyboard diagram showing home-row keys

## Steps

1. Open the text editor. Hands on home row if learners are ready; otherwise hunt-and-peck is fine today. Say: “Speed comes later—accuracy first.”
2. Type the sentence: `Today I practiced typing on my Linux computer.` Read it aloud together once before typing.
3. On the next line, type one sentence about a hobby or food they like—**no addresses, phone numbers, or full names**.
4. Use **Backspace** on purpose to fix one word. Show that mistakes are normal. Save the file to `Saturday/lesson-4` as `typing.txt` (create the folder if needed).
5. Select all text (Ctrl+A) and change font size once from the editor menu so they see text can be adjusted for reading comfort.

## If the room is chaotic (10 minutes)

Open a typing practice page in the browser only if your site already allows it (for example a simple public typing tutor). Otherwise, type the single sentence from step 2 together as a group chant while each person types slowly.

## Done looks like

- `Saturday/lesson-4/typing.txt` (or equivalent path) exists with at least two sentences.
- Learners used Backspace to fix a typo at least once.
- Files saved under `Saturday`, not on Desktop.
