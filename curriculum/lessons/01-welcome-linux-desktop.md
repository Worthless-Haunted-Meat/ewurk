# Welcome and the Linux desktop

EWURK topic: **Lesson 1 — Welcome and the Linux desktop**

## Goal

Everyone can sign in to the lab computer, find the web browser and home folder, and shut down the machine respectfully at the end of class.

## Materials

- EWURK lab Linux desktop (keyboard, mouse, monitor)
- Printed sheet with today’s login card format (username only — no passwords on paper)
- Instructor copy of the Wi‑Fi name if the site uses wireless (optional; class works offline)

## Steps

1. Gather in a circle. Explain that these computers are on loan through EWURK and we treat them gently — food and drinks away from the keyboard.
2. Help each family sign in with the username on their card. Point out the **panel** (taskbar), **Activities** or app menu, and the **Firefox** (or Chromium) icon.
3. Open the **Files** app and click **Home**. Have each learner create a folder named `Saturday` and say out loud: “This is where today’s work lives.”
4. Open the browser, go to `about:blank`, and type one sentence about something they enjoy (no full names needed).
5. Before leaving, save nothing private on the desktop; log out from the system menu and push chairs in.

## If the room is chaotic (10 minutes)

Switch to a “mouse tour”: trackpad or mouse only — click icons, drag a window, minimize and restore. No typing required. Praise calm hands.

## Done looks like

- Each family logged in once and opened Files and a browser.
- `Saturday` folder exists in Home for each machine you checked.
- Machines are logged out and desks are tidy.
