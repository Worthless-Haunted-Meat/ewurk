# Files and folders

EWURK topic: **Lesson 3 — Files and folders**

Instructor: read each numbered step aloud. Attendance is marked in EWURK after class—not on this page.

## Goal

Everyone can open the file manager, find their Home folder and the `Saturday` folder from Lesson 1, and save a short text file in the right place.

## Materials

- EWURK lab Linux desktop
- Files app (Nautilus or similar file manager)
- Simple text editor (Text Editor, gedit, or similar)

## Steps

1. Open **Files** and click **Home**. Find the `Saturday` folder (create it again if someone is new today).
2. Inside `Saturday`, create a folder named `lesson-3`. Explain: “Folders keep our work sorted so we do not lose files on the desktop.”
3. Open the **text editor** from the app menu. Type three lines: today’s date, one thing they learned last week in browser class, and one goal for today (no full names).
4. Click **Save** (or File → Save). Navigate to Home → `Saturday` → `lesson-3`. Save as `notes.txt`.
5. In Files, double-click `notes.txt` to open it again. Close the editor and Files cleanly before the next activity.

## If the room is chaotic (10 minutes)

Only practice opening Files and clicking Home → `Saturday`. Drag one sample file icon if the lab has a shared read-only folder; no saving required.

## Done looks like

- `Saturday/lesson-3/notes.txt` exists on each machine you spot-check.
- Learners can point to Home and `Saturday` without help.
- No personal files left on the Desktop.
