# Month celebration project

EWURK topic: **Lesson 10 — Month celebration project**

Instructor: read each numbered step aloud. Attendance is marked in EWURK after class—not on this page.

## Goal

Families celebrate four weeks of practice by building a small **team slide** (one text file or simple HTML page) that lists skills learned—browser, files, typing, safety—and present it in two minutes per group.

## Materials

- EWURK lab Linux desktop
- Text editor and browser
- Optional: projector for mini-presentations

## Steps

1. In groups of two or three, open `Saturday` and create `lesson-10/celebration.txt` (or `celebration.html` if staff prefer).
2. Together list **five skills** from the month (e.g. tabs, bookmarks, save a file, screenshot, ask for help). Use the lesson numbers if helpful (Lessons 1–9).
3. Add one line: “Our team is proud of ___” with a fictional team name—no full names of children required.
4. Each group reads their file aloud (or staff displays it). Applause after each—no grades, no ranking.
5. Log out, tidy desks, and remind families attendance for today is marked in **EWURK** after they leave.

## If the room is chaotic (10 minutes)

Whole-room chant: name lessons 1–9 from the index page on the projector while everyone echoes. Skip presentations; still end with logout practice.

## Done looks like

- Every group has a `Saturday/lesson-10/` file listing multiple skills.
- Each learner can name one thing they can do on the Linux desktop that they could not do four weeks ago.
- Machines logged out; instructor ready to mark roster in EWURK.
