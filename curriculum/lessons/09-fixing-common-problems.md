# Fixing common problems

EWURK topic: **Lesson 9 — Fixing common problems**

Instructor: read each numbered step aloud. Attendance is marked in EWURK after class—not on this page.

## Goal

Everyone can try three calm fixes—refresh the page, check cables, ask for help—before panicking when something goes wrong on the Linux desktop.

## Materials

- EWURK lab Linux desktop
- Browser and Files app
- Posted “help ladder” sign: (1) wait (2) refresh (3) ask neighbor (4) raise hand for staff

## Steps

1. Review the **help ladder** on the wall. Practice raising a hand instead of shouting—staff want to help.
2. In the browser, open any approved page. Press **F5** or the refresh button. Say: “Refresh fixes many glitches; it does not break the computer.”
3. Open **Files**. If a folder looks empty, click **Home** again and re-open `Saturday`. Explain sometimes the view needs a moment—close and reopen the app once.
4. **Cables:** look at mouse and keyboard plugs without pulling hard. If something is loose, staff fixes it—learners notify, not yank.
5. Write in the text editor: “When I am stuck I will ___” (fill: refresh, ask neighbor, raise hand). Save to `Saturday/lesson-9/help-plan.txt`.

## If the room is chaotic (10 minutes)

Only practice the help ladder call-and-response and F5 refresh on one shared page—no file saving.

## Done looks like

- Learners demonstrated refresh once and can repeat the help ladder order.
- `Saturday/lesson-9/help-plan.txt` exists on spot-checked machines (or group completed verbal version if chaos fallback used).
- No one attempts admin passwords or system settings changes.
