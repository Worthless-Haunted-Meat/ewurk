# Browser basics

EWURK topic: **Lesson 2 — Browser basics**

Instructor: read each numbered step aloud. Pause for questions. Attendance is marked in EWURK after class—not on this page.

## Goal

Everyone can open the web browser, use tabs, type a web address, and bookmark a page they might need again next week.

## Materials

- EWURK lab Linux desktop with Firefox or Chromium installed
- Whiteboard or flip chart (optional) to sketch “address bar” vs “search box”

## Steps

1. Open the browser from the taskbar or Activities menu. Point to the **address bar** at the top and say: “This is where we type a site name when we already know it.”
2. Type `https://www.wikipedia.org` and press Enter. Wait for the page to load. If it is slow, say: “Loading is normal—no clicking wild buttons.”
3. Open a **new tab** (plus icon or Ctrl+T). In the second tab, visit `https://www.khanacademy.org` or another education site your site approves.
4. Switch between tabs by clicking them. Close one tab with the × and reopen it from history if someone closes the wrong one (Ctrl+Shift+T often reopens).
5. On a page the class likes, click the **star** or bookmark icon and save to the default bookmarks folder. Name it `Saturday class` so it is easy to find.

## If the room is chaotic (10 minutes)

Stop navigation. Have everyone open exactly one tab to `about:blank` and practice only: new tab, close tab, undo close. No new URLs.

## Done looks like

- Each learner opened at least two tabs and switched between them.
- At least one bookmark named `Saturday class` exists on each checked machine.
- Browser is closed or left on a harmless home page before logout.
