# Search and trustworthy sites

EWURK topic: **Lesson 6 — Search and trustworthy sites**

Instructor: read each numbered step aloud. Attendance is marked in EWURK after class—not on this page.

## Goal

Everyone can run a simple web search, open two results, and explain one reason a page might or might not be trustworthy—without copying text they do not understand.

## Materials

- EWURK lab Linux desktop with browser
- Printed slip with two allowed search topics (e.g. “how plants grow,” “public library hours in [your city]”)—avoid medical or scary topics

## Steps

1. Open the browser to your program’s approved search engine home page (or `https://www.wikipedia.org` if search is restricted). Show the **search box** vs the **address bar** again from Lesson 2.
2. Search the first approved topic together. Open the **first** result in a new tab. Skim the title and first paragraph aloud—stop if content feels confusing or upsetting and pick another result.
3. Open a **second** result for the same question. Ask: “Do these pages agree? Which looks more official?” (look for clear author, date, no pop-up spam).
4. In the text editor, type one sentence: “I learned ___ from [site name].” Use only the site title—no copying long paragraphs (plagiarism and safety).
5. Save the sentence to `Saturday/lesson-6/search-notes.txt`. Close extra tabs so only one or two remain.

## If the room is chaotic (10 minutes)

Use a single pre-bookmarked trustworthy page (Wikipedia article or local library site). Everyone practices scroll up/down and find in page (Ctrl+F) for one word only.

## Done looks like

- Each learner completed one search and viewed two results with supervision.
- `Saturday/lesson-6/search-notes.txt` exists with one original sentence.
- No personal information typed into search boxes.
